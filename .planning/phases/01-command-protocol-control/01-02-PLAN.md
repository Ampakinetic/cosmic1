<objective>
Close the four protocol-level defects (CR-01, CR-02, CR-03, CR-04 + WR-03/WR-04/WR-05) that the Phase 1 verifier proved deterministically break the command link. After this plan, a serialized command survives the balloon's CRC validation for every sequence number, embedded CR/LF byte pairs no longer truncate packets, transmit failures reach the FAILED terminal state with pacing, and GET_STATUS responses are typed correctly end to end.

Purpose: SC-2 ("LoRa command packets transmitted from base station to balloon and acknowledged") is currently failed by arithmetic-level defects, not hardware. This plan makes the wire protocol correct so CTRL-01/CTRL-06/PRI-02 become hardware-verifiable instead of code-broken.
Output: Fixed command_protocol.h/.cpp, command_sender.h/.cpp, command_handler framing/response-typing in command_handler.cpp, plus a host-side wire-format regression script.
</objective>
