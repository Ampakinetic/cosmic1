  Create the WiFi manager and replace the hardcoded init:

  1. src/wifi_manager.h/.cpp: class WiFiManager with begin()/update()/requestSwitch()/getStatus()/resetJoinError(); singleton `extern WiFiManager& WiFiMgr();`. Persistence: Preferences namespace "wifi" — mode (u8: 0 = AP default, 1 = STA), ssid (<= 32 chars), pass (<= 63 chars). The AP credentials (WIFI_SSID "Cosmic1-BaseStation", WIFI_PASSWORD, WIFI_CHANNEL 6, MAX_CONNECTIONS 4) move from main_basestation.cpp ~40-43 into wifi_manager.cpp as compile-time constants — they are never persisted and never editable from the UI (CONTEXT: only station credentials are user data; wifi_config.h belongs to the balloon legacy app, do not touch it).

  2. begin(): WiFi.persistent(false) (stop stale core-NVS autoconnect), load prefs; if mode == STA and ssid non-empty -> WiFi.mode(WIFI_STA) + WiFi.begin(ssid, pass), state = JOINING, joinDeadlineMs = millis() + 20000; else AP path: WiFi.mode(WIFI_AP) + softAP(constants) exactly as today, state = ACTIVE_AP.

  3. update() — ticked from loop(), never blocking: in JOINING, WL_CONNECTED -> confirm the STA interface and drop any interface kept up during the join (the module tears the old interface down the moment the new one confirms — it never parks the radio in a dual-mode steady state), state = ACTIVE_STA; millis() > joinDeadlineMs -> revert to AP (softAP up on the constant credentials), state = ACTIVE_AP with joinErrorSsid = the failed ssid (reset by resetJoinError or a later successful switch). During a runtime AP->STA switch the AP interface stays up until WL_CONNECTED so the operator keeps the fallback UI reachable; server.handleClient() keeps running throughout because update() is non-blocking (the D-26 millis-timer idiom).

  4. requestSwitch(mode, ssid, pass): persist the new mode (+credentials for STA) to NVS FIRST — a reboot mid-switch honors the operator's choice — then drive the state machine: to STA -> enter JOINING with a fresh 20 s deadline while keeping the current interface serving; to AP -> bring softAP up and drop STA.

  5. getStatus(): WifiStatus { activeMode ("AP" | "STA" from the actual serving state), ip (WiFi.softAPIP() or WiFi.localIP() as appropriate), joining (bool), errorSsid (string, empty unless the last join failed) } — queried truth only.

  6. src/main_basestation.cpp: initWiFi() body becomes WiFiMgr().begin() (constants removed from main); loop() gains WiFiMgr().update(); POST /wifi route — args mode ("ap" | "sta"), ssid, password; WR-07 validation: for Station, ssid required and <= 32 chars, password required 8-63 chars; for AP no credential args are read; invalid input -> 400 with the locked copy ("Check the network name and password, then try again." family per UI-SPEC); persist failure -> 500 "Failed to apply WiFi settings". handleApiState gains "wifi":{"mode":"...","ip":"...","joining":b,"errorSsid":"..."} — the password NEVER appears in any response.

  7. platformio.ini: add -<wifi_manager.cpp> to the balloon env build_src_filter (base-only module).
