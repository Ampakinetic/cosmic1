# Cosmic1 - Base Station Camera Control Extension

ESP32-S3 balloon tracking system with remote camera control, image transmission over LoRa, and real-time web interface.

## Project Overview

**What this is:** Extension to existing ESP32-S3 balloon tracking platform. Base station becomes remote control panel for balloon camera, with live telemetry and GPS tracking on OpenStreetMap.

**Core Value:** Users can remotely control the balloon camera and view captured images through the base station web interface, with real-time telemetry and map tracking always available.

**Status:** Phase 1 - Command Protocol & Control (Not Started)

**Mode:** Vertical MVP - each phase delivers end-to-end user capability

## Current Work

**Phase 1: Command Protocol & Control**
- Establish bidirectional LoRa communication for camera control
- Base station sends camera commands → balloon executes → acknowledgment
- Manual trigger + interval-based auto-capture
- Retry logic with timeout

## Architecture

**Balloon Unit (Transmitter):**
- ESP32-S3 with camera module
- BMP280 pressure/temperature sensor
- MAX-M10S GPS module
- LoRa E32 900T30D radio
- Existing WiFi camera interface (unchanged)

**Base Station (Receiver):**
- ESP32-S3 with LoRa receiver
- SD card for image storage
- WiFi AP/Station for web interface
- Enhanced web UI for camera control + telemetry display

## Stack

**Languages:** C++ (ESP32 firmware), HTML/CSS/JavaScript (web interface)

**Frameworks:** Arduino Framework (ESP32-S3), PlatformIO build system

**Libraries:** esp32-camera, Adafruit BMP280, TinyGPSPlus, LoRa (Sandeep Mistry), ArduinoJson

## Key Constraints

- LoRa bandwidth: 240 bytes per packet
- Telemetry always has priority over image data
- 5-second UI update rate
- Single-threaded event loop (no blocking)
- PSRAM required for camera operations
